# Awesome AI Proofs

AI-assisted results in mathematics and statistics, organized by problem. Each entry lists models, papers, proof artifacts, reported verification and caveats. Unsuccessful attempts and corrections are included under the relevant research question.

[Website](https://subroy13.github.io/awesome-ai-proofs/) · [Visualizations](https://subroy13.github.io/awesome-ai-proofs/visualizations.html) · [Contributing](CONTRIBUTING.md)

The website is available after GitHub Pages is enabled and the deployment workflow runs. Evidence labels describe the linked reports; they do not indicate an independent proof audit by this repository. Individual attempt pages identify what was checked.
