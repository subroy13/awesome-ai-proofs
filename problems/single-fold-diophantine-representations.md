OpenAI's internal frontier model proved and formalized in Lean the main result of 'Single-fold Diophantine representations'. Every recursively enumerable set of natural-number tuples has a polynomial Diophantine representation with exactly one complete auxiliary tuple for each member. This proves the single-fold conjecture and, consequently, the finite-fold conjecture.
